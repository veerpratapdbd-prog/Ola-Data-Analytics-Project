# 🚖 OLA Ride Data Analytics Dashboard (SQL + Power BI)

### 📊 Project Overview
This project presents a **comprehensive data analysis of Ola ride bookings** for the month of **July 2024**, integrating **SQL** for data processing and **Power BI** for visualization.  
The dashboard offers deep insights into **overall bookings, revenue performance, cancellations, vehicle types, and customer-driver ratings** to help business teams track KPIs and improve service quality.

---

### 🧩 Tools & Technologies Used
- **SQL Server** – Data cleaning, transformation, and analysis  
- **Microsoft Excel** – Data storage and pre-processing  
- **Power BI** – Interactive dashboard and data visualization  
- **DAX & Power Query** – Data modeling and measures

---

### 🗂️ Project Workflow
1. **Data Extraction (SQL):**  
   Dataset loaded into SQL for data validation, filtering, and aggregation.  
   Queries are stored in: `Ola_data_Analytics_Project_SQL_V2F_pdf`

2. **Data Cleaning (Excel/SQL):**  
   Removed duplicates, handled nulls, standardized date & payment fields.

3. **Data Visualization (Power BI):**  
   Created an interactive 5-page dashboard using multiple visuals and KPIs:
   - **Overall Performance**
   - **Vehicle Type Analysis**
   - **Revenue Breakdown**
   - **Cancellation Insights**
   - **Ratings Overview**

---

### 📈 Dashboard Insights

#### 🏁 Overall Page
- **Total Bookings:** 103,024  
- **Total Booking Value:** ₹35M  
- **Booking Success Rate:** 62.09% successful rides  
- **Ride Volume Trend:** Steady performance with spikes on weekends

#### 🚗 Vehicle Type Page
- Compared **average & total distances** across vehicle types (Car, SUV, Bike, Auto, etc.)
- Highest average distance: ~25 km  
- Total booking value ranged between ₹4.8M–₹5.2M per vehicle type

#### 💰 Revenue Page
- Major revenue generated from **Cash and UPI** payments  
- Top 5 customers contributed significantly to total revenue  
- Revenue maintained a consistent growth trend throughout July

#### ❌ Cancellation Page
- **Cancellation Rate:** 28.08%  
- **Top Customer Reasons:** Driver not moving / Change of plans  
- **Top Driver Reasons:** Car/personal issues / Customer no-show  

#### ⭐ Ratings Page
- **Driver Ratings:** 3.98 – 4.01  
- **Customer Ratings:** 3.99 – 4.01  
- Consistently high satisfaction across all vehicle types

---

### 🧠 Key Insights & Learnings
- High dependency on **Cash/UPI payments** highlights need for promoting digital methods.  
- Around **28% cancellation rate** indicates operational inefficiencies.  
- **Consistent 4.0+ ratings** reflect strong customer and driver engagement.  
- Data-driven analysis helps identify performance gaps by vehicle category.
